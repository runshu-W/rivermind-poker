# RiverMind Beta 范围

## 定位

Beta 不是完整 H2N，也不是缩水版 GTO Wizard。它是一个能完成以下闭环的 H2N-lite：

```text
导入真实牌谱 → 找到重复漏洞 → 看懂原因 → 生成复习任务
```

牌谱分析建立用户入口和数据底座，GTO 解法与专用策略模型随后接入同一套规范化节点。

## 8–12 周目标

### 必须交付

- 两种优先牌谱格式，先支持英文文本；
- 6-max Cash 与 MTT 基础规范化；
- 文件/文件夹导入、去重、错误隔离和导入报告；
- Session、盈亏、All-in EV、位置和街道报告；
- 固定核心统计：VPIP、PFR、3Bet、Fold to 3Bet、CBet 等；
- 常用快速过滤；
- 手牌回放、标签、收藏和导出；
- 基于确定性统计规则的漏洞检测；
- LLM 将结构化漏洞证据转成中文解释和复习计划；
- 数据删除、导出和授权控制。

### 可选交付

- 20–50 个高频场景的经过验证 GTO 解法；
- 从漏洞节点跳到一个简单 Study 页面；
- 教练分享链接。

### 明确不做

- 实时 HUD、悬浮窗和自动读屏；
- 自定义统计 DSL 和 HUD/Popup 编辑器；
- 大规模玩家池数据交易；
- 任意场景实时 GTO 求解；
- LLM 直接给出可执行扑克动作；
- 一次性兼容数十个平台。

## Beta 验收

- 黄金牌谱解析通过率 100%；
- 无法识别的牌谱明确失败，不静默猜测；
- 相同文件重复导入不产生重复手牌；
- 核心统计和人工计算黄金集一致；
- 用户能在 5 分钟内完成首次导入并找到一手值得复盘的牌；
- LLM 中所有数值均来自结构化证据；
- 30 名种子用户中至少 15 名连续使用两周。
